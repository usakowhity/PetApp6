# 🐇 PetApp6 v1.1.0 – 癒しウサギの日記帳

PetApp6 は、PetApp5 v3.2.7 の機能・ファイル構成・世界観を継承し、その上に日記帳機能を追加したアプリです。

PetApp5 の世界観である Direct Talk、音声認識、Diary → Emotion／Need → Rabbit Action、Idle Layer を土台として、日記の保存・一覧・詳細表示・編集・削除、サムネール付き日記帳の印刷／PDF保存に対応しています。

今回の v1.1.0 では、Direct Talk に R20「トイレ」アクションを追加します。既存機能や既存資産を不用意に削除せず、必要な機能を差分追加する方針を維持します。

---

## 🟩 1. 概要

PetApp6 は、PetApp5 を作り替えるのではなく、**既存の機能・モジュール・画像資産を活用しながら新しい機能を追加するアプリ**です。

### 主な機能

- ユーザーが自由に設定できるペット名
- Direct Talk（設定したペット名で話しかける機能）
- SpeechRecognition による音声認識
- 日記の保存・一覧・詳細表示
- 日記に対応するウサギのアクション画像の表示
- 日記本文の編集・削除
- サムネール付き日記帳の印刷／PDF保存
- Rabbit Action R01〜R20
- 時間帯に応じた Idle Layer

## 🎙️ 3. Direct Talk の使い方

Direct Talk は、ユーザーが設定したペット名を呼びかけの先頭につけて、ウサギに話しかける機能です。

例えば、ペット名が「レオ」の場合は、次のように呼びかけます。

- 「レオ、おはよう」
- 「レオ、元気？」
- 「レオ、かわいい」
- 「レオ、おやすみ」
- 「レオ、ごはん」
- 「レオ、お水」
- 「レオ、トイレ」

ペット名を「うさこ」に設定した場合は、「うさこ、かわいい」「うさこ、トイレ」のように呼びかけます。

**ペット名は「レオ」に固定されていません。** ユーザーが設定した名前を使って呼びかけることができます。

話しかけ内容に対応する Direct Talk 辞書に基づいて、ウサギが対応するアクションを実行します。

### Direct Talk 辞書（PetApp6 v1.1.0）

| 話しかけ内容 | アクションID | 意味 |
|---|---|---|
| おはよう | R10 | 朝のあいさつ |
| 元気 | R11 | 元気確認 |
| かわいい／可愛い／カワイイ／おりこう／お利口 | R14 | 喜び反応 |
| おやすみ | R15 | 休息 |
| ねんね | R08 | 眠る反応 |
| おいで | R16 | 呼びかけへの反応 |
| ごはん | R19 | 食事行動 |
| 牧草／チモシー | R17 | 食事行動（草） |
| 水／お水 | R18 | 飲水行動 |
| お腹すいた | R03 | 空腹反応 |
| トイレ／おしっこ／ちっち／シーして／シー | R20 | トイレの反応 |

## 🟨 4. PetApp6 の日記帳機能

### 4.1 日記の保存

日記本文と日付などの情報を、ブラウザの `localStorage` に保存します。

### 4.2 日記一覧

保存済みの日記を新しい順に一覧表示します。一覧には日付、本文の冒頭、対応するウサギのアクションサムネールを表示します。

### 4.3 日記詳細

日記詳細画面では、次の内容を表示します。

- 日付
- 日記本文（改行を保持）
- 日記に対応するウサギのアクション画像
- 編集・追記ボタン
- 削除ボタン
- 日記一覧に戻るボタン

詳細画面では、Emotion／Need の値ではなく、**日記本文とウサギのアクション画像を中心に表示**します。

### 4.4 日記の編集・追記

保存済みの日記本文や日付を編集して保存できます。追記機能を使う場合は、元の本文を残しながら文章を追加します。

### 4.5 日記の削除

選択した日記を削除し、更新された一覧を表示します。削除時には確認メッセージを表示します。

### 4.6 サムネール付き日記帳の印刷／PDF保存

保存済みの日記を印刷用レイアウトにまとめて出力できます。日記ごとに、日付・本文・対応するウサギのアクション画像・アクション名（定義されている場合）を表示します。

ブラウザ標準の印刷機能を使用するため、PDF生成用の外部ライブラリは必要ありません。印刷画面で「PDFとして保存」を選択するとPDFファイルとして保存でき、プリンターを選択すれば紙に印刷できます。

## ✏️ 6. 日記帳の使い方

### ① 日記を書く

画面の「今日の日記」カードにあるテキストエリアに、日々の出来事や気持ちを書きます。

例：

```text
今日ちょっと疲れたけど、ウサギに癒された。
```

### ② 「ウサギに聞かせる」ボタンを押す

入力した文章を日記として保存し、ウサギの反応を表示する処理を実行します。

日記データには、ID、日付、本文などを保存します。Emotion／Need の保存値は、v1 系では原則として `null` です。日記に対応するアクションが選択された場合は、`actionId` にそのアクションIDを保存します。

### ③ 日記一覧を見る

「日記帳」カードに保存済みの日記が新しい順に表示されます。

- 日付を表示
- 本文の冒頭を表示
- 対応するウサギのアクションサムネールを表示
- 一覧から日記を選択して詳細画面を開く

### ④ 日記詳細を見る

一覧から日記を選ぶと詳細画面に切り替わります。日付、本文、対応するウサギのアクション画像を確認できます。

### ⑤ 日記を編集・追記する

詳細画面の「編集・追記」ボタンを押し、本文や日付を修正して保存します。変更内容は日記一覧にも反映されます。

### ⑥ 日記を削除する

詳細画面の「削除」ボタンから、選択した日記を削除できます。確認画面で削除を確定すると、日記一覧が更新されます。

### ⑦ 日記一覧に戻る

詳細画面の「日記一覧に戻る」ボタンを押すと、日記一覧に戻ります。

## 🖨️ 7. 日記帳を印刷／PDF保存する方法

### ① 日記を保存しておく

日記を入力して「ウサギに聞かせる」ボタンを押し、日記帳に保存します。保存済みの日記を印刷用日記帳にまとめて出力できます。

### ② 「印刷／PDF保存」ボタンを押す

日記帳画面にある「🖨️ 印刷／PDF保存」ボタンを押します。印刷用レイアウトが組み立てられ、ブラウザの印刷ダイアログが開きます。

### ③ PDFとして保存する、または印刷する

印刷ダイアログで、次のいずれかを選択します。

- **PDFとして保存：** 日記帳をPDFファイルとして保存します。
- **プリンターを選択：** 日記帳を紙に印刷します。

### ④ 書き出される内容

日記ごとに、次の内容を掲載します。

- 日付
- 本文（改行を保持）
- ウサギのアクションサムネール
- アクション名（定義されている場合）

### ⑤ サムネールがない日記について

過去の日記など、アクションIDが保存されていない日記や対応画像を特定できない日記では、反応画像がないことを示すメッセージを表示します。

## 💾 8. 日記データの保存場所

日記はブラウザの `localStorage` に保存します。

保存に使用するキー名：

```text
petapp6_diaries
```

この名前はファイル名ではなく、ブラウザの保存領域で使用するキー名です。

日記データは基本的に、同じブラウザ・同じオリジンの範囲で管理されます。別のブラウザや別のオリジンでアプリを開いた場合は、保存データが共有されないことがあります。

PDFとして保存したファイルは、ブラウザの印刷機能を通じて別途保存されます。

### 日記データの基本形式

```json
{
  "id": "2026-10-12T09:15:23.123Z",
  "date": "2026-10-12",
  "text": "今日は少し疲れたけど、ウサギに癒された。",
  "emotion": null,
  "need": null,
  "actionId": "R20"
}
```

- `id`：日記を識別するID
- `date`：日付（`YYYY-MM-DD`）
- `text`：日記本文（改行を保持）
- `emotion`／`need`：v1 系の互換性維持用。保存値は原則 `null`
- `actionId`：日記に対応するウサギのアクションID。旧データでは存在しない場合があります

## 🔍 9. 保存された日記を確認する方法

### Chrome／Microsoft Edge の場合

1. PetApp6 を開きます。
2. `F12` キーを押して開発者ツールを開きます。
3. 「Application」（日本語 UI では「アプリケーション」）を選択します。
4. 「Storage」→「Local Storage」を開きます。
5. PetApp6 を開いているオリジンを選択します。
6. キー一覧から `petapp6_diaries` を探します。
7. 値を確認すると、保存されている日記データを確認できます。

メニューの名称や配置は、ブラウザのバージョンによって異なる場合があります。

## 🧩 10. 今後の拡張候補

PetApp6 v1.1.0 では、日記の保存・一覧・詳細表示・編集・削除に加え、日記に対応するウサギのアクション画像の表示、サムネール付き日記帳の印刷／PDF保存、Direct Talk の R20「トイレ」アクションに対応します。

今後の拡張候補は次のとおりです。

- 日記検索
- タグ機能
- 日記データのエクスポート／インポート（バックアップ・復元）
- 日記とウサギの反応履歴を、複数回の反応や時系列で記録・閲覧する機能
- データのバックアップ機能の拡充
- 必要性を検討したうえでの Emotion／Need 判定機能の高度化

LLM による Emotion／Need 判定は必須機能には含めません。再導入する場合は、プライバシー、実行コスト、速度、分類精度などを検討してから設計します。

## 🐇 11. 開発方針

> **既存機能を削らず、既存モジュールと資産を温存しながら、新しい層を追加する。**

PetApp6 は差分追加型で開発します。

- PetApp5 の既存機能を不用意に削除しない
- 既存の JavaScript モジュールや画像資産を活用する
- 日記帳機能は独立したモジュールに分けて管理する
- Direct Talk の追加アクションは既存の仕組みを活用して実装する
- 既存機能と追加機能の共存を重視する
- 将来の拡張に必要な基盤を維持する

**機能を使わないことはあっても、将来必要な基盤を削らない。**

この原則を PetApp6 シリーズの開発方針とします。
